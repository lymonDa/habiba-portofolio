## 🌟 Overview

This is the personal portfolio of **Habeeba Yasser Hassen El-Sawaf** — an **Electrical Power Engineering** student at **Al-Azhar University** (class of 2028), event photographer, and media team leader based in **Qena, Egypt**.

The website blends editorial aesthetics with interactive web motion to showcase both facets of her journey:
1. **Visual Storytelling & Photography**: Capturing authentic atmosphere, workshops, celebrations, and Egyptian light.
2. **Engineering Discipline**: Industrial training, power systems, microcontrollers, and technical leadership.

---

## ✨ Features

- **Cinematic Hero**: Scroll-driven storytelling with sunrise atmosphere and ambient media.
- **Dynamic Photography Gallery**: Filterable category mosaic featuring:
  - Events & Conferences
  - Technical Workshops
  - Engagements & Celebrations
  - Nature & Egyptian Light
  - Product Photography
- **Parallax & Motion Storytelling**: Multi-layered depth effects, smooth reveals, and typography transitions.
- **Engineering Timeline**: Documented industry training, credentials, and hands-on exposure.
- **Leadership & Student Activities**: Showcasing leadership roles across Hult Prize, IEEE, and civil initiatives.
- **Interactive Contact Form**: Direct channels via Email, WhatsApp, LinkedIn, and Instagram.
- **Fast & Lightweight**: Built with modern web standards and bundled with Vite for near-instant load times.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or newer recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/lymonDa/habiba-portofolio.git
   cd habiba-portofolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### Available Scripts

- `npm run dev`: Starts the local development server at port 3000.
- `npm run build`: Generates the optimized production build in the `dist/` directory.
- `npm run preview`: Previews the production build locally.
- `npm test`: Runs automated browser validation scripts.
